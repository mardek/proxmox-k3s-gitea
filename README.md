# Proxmox + K3s + Gitea Lab

Homelab infrastructure-as-code: four Debian VMs on Proxmox, K3s bootstrapped via Cloud-Init, Gitea via Helm, and optional Longhorn RWX distributed storage.

## Architecture

```
Proxmox Host (bao)
├── VM 100: k3s-control   (192.168.2.100) — control plane
├── VM 101: k3s-worker-1  (192.168.2.101)
├── VM 102: k3s-worker-2  (192.168.2.102)
├── VM 103: k3s-worker-3  (192.168.2.103)
└── VM 9000: debian-12-cloud (template)
```

## Quick Start

```bash
# 1. Proxmox credentials and SSH key in agent
export PROXMOX_VE_API_TOKEN="root@pam!tokenname=uuid"
ssh-add ~/.ssh/id_ed25519

# 2. Create VMs (Terraform)
cp 01-vms/terraform.tfvars.example 01-vms/terraform.tfvars
# edit 01-vms/terraform.tfvars
terraform -chdir=01-vms init
terraform -chdir=01-vms apply

# 3. Wait for cluster
02-kubernetes/wait-for-cluster.sh 4 600

# 4. Deploy Gitea
export GITEA_ADMIN_PASSWORD='choose-strong-password'
03-gitea/install.sh

# 5. Access Gitea
run.sh
```

## Storage

| Class | Backend | Access | Replicas |
|-------|---------|--------|----------|
| `local-path` | Host disk | RWO | 1 |
| `longhorn-rwx` | Longhorn | RWX | 3 |

## Secrets

- `PROXMOX_VE_API_TOKEN` — environment variable, never committed
- `GITEA_ADMIN_PASSWORD` — environment variable, passed to installer
- K3s token — generated by Terraform `random_password`, stored in state
