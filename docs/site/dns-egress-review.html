DNS & Egress Networking Review

DNS in Kubernetes

CoreDNS runs in the kube-system namespace and handles service discovery. Pods use the cluster DNS to resolve service names to ClusterIP addresses.

# Check CoreDNS pods
kubectl get pods -n kube-system -l k8s-app=kube-dns

# Test DNS from a pod
kubectl run -it --rm debug --image=busybox:1.28 --restart=Never -- nslookup kubernetes.default

Egress Traffic

By default, all pods can initiate outbound connections. NetworkPolicies can restrict egress to specific destinations.

# Example: allow egress only to specific CIDR
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-egress
spec:
  podSelector: {}
  policyTypes:
  - Egress
  egress:
  - to:
    - ipBlock:
        cidr: 10.0.0.0/8
